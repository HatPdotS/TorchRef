# Figure 4: Difference Refinement of IBL Isomerization in Tubulin

## Overview

This figure demonstrates TorchRef's difference refinement capability on a time-resolved
crystallography dataset: light-induced *cis*-to-*trans* isomerization of the IBL ligand
in tubulin (PDB: 8QL2 dark, 7YYZ light).

## Method

The key idea is to refine the light-state structure directly against the difference signal,
rather than relying on extrapolated structure factor amplitudes.

### Input data

| File | Description |
|------|-------------|
| `data/8QL2.pdb` | Dark-state (ground) structure (~1.4 MB) |
| `data/7YYZ.pdb` | Published light-state structure from extrapolation (707 KB) |
| `data/torchref_0p18.pdb` | TorchRef-refined light-state structure (690 KB) |
| `data/dark-phenix.mtz` | Dark-state reflection data (7.6 MB) |
| `data/7YYZ-light.mtz` | Light-state reflection data (2.9 MB) |
| `data/IBL_grade.cif` | IBL ligand geometry restraints (32 KB) |

### Difference refinement

The refinement is a two-stage process:

**Stage 1 — Automated difference refinement** using TorchRef's `difference-refine` CLI,
which implements a MixedModel framework with a difference target. The dark structure (8QL2)
is held fixed while the light structure is refined against the difference between the
light and dark structure factor amplitudes:

```bash
torchref.difference-refine \
    -lm work.pdb -dm data/8QL2.pdb \
    -lsf data/7YYZ-light.mtz -dsf data/dark-phenix.mtz \
    --fraction 0.18 --cif data/IBL_grade.cif \
    -o refinement_output --dmin 1.9 \
    --weight-schedule 10,5,2 --n-cycles 10
```

Key parameters:
- **Starting model**: 8QL2 (dark state) — the light structure is initialized from the dark
- **Fraction**: 0.18 (18% light, 82% dark occupancy)
- **Resolution**: 1.9 A
- **Weight schedule**: geometry weights decrease over cycles (10 -> 5 -> 2) to allow
  the model to first satisfy geometry, then fit the density more closely
- **Target**: difference target on the amplitude differences, with geometry
  and ADP restraints on the light model

The refinement script is: `run_difference_refine.sh`

**Stage 2 — Manual real-space refinement** in Coot against the 2Fext-Fc difference
electron density map (from the `difference_data.mtz` output). This step speeds up
convergence for the IBL ligand, which requires large conformational changes
(*trans* to *cis*). The Coot-refined coordinates were saved as `work.pdb` and used
as the starting model for automated refinement (Stage 1).

These steps were repeated multiple times until the structure converged. 

### Output

The refinement produces a pair of PDB files (dark + light) and the difference data MTZ:

| File | Description |
|------|-------------|
| `refinement_output/fractions_82_18_light.pdb` | Refined light-state structure |
| `refinement_output/fractions_82_18_dark.pdb` | Dark-state structure (unchanged) |
| `refinement_output/fractions_82_18_difference_data.mtz` | Difference data with map coefficients |
| `refinement_output/fractions_82_18_summary.json` | Refinement parameters and statistics |

## Validation

Validation compares the TorchRef difference-refined structure against the published
extrapolated structure (7YYZ) using difference electron density (DED) correlation.
The `torchref.validate-ded` tool computes real-space and reciprocal-space correlation
coefficients between the model-predicted DED and the observed DED.

Four validation scenarios are computed:

| Scenario | Light model | Selection | Description |
|----------|-------------|-----------|-------------|
| `torchref_IBL` | TorchRef refined | IBL residue | DED correlation at IBL ligand only |
| `torchref_FULL` | TorchRef refined | Full chain A+B | DED correlation across all atoms |
| `extrapol_IBL` | 7YYZ (extrapolated) | IBL residue | Baseline comparison at IBL |
| `extrapol_FULL` | 7YYZ (extrapolated) | Full chain A+B | Baseline comparison, all atoms |

To regenerate validation results (including CCP4 maps for PyMOL rendering):

```bash
cd validation
bash run_validation.sh
```

Validation results (JSON + PNG) are in `validation/output/`.

## Figure Panels

The figure panels are PyMOL renders with difference density maps, generated by two
scripts: one for the IBL ligand close-up and one for the binding pocket view.
Both use a consistent color scheme: dark (gray80), extrapolated/7YYZ (wheat),
TorchRef refined (marine).

**Ligand panels** (`figure4_ligand.pml`):

| Panel | File | Content |
|-------|------|---------|
| 11 | `panels/figure4_panel_11.png` | WDFo + dark + extrapolated (7YYZ) |
| 12 | `panels/figure4_panel_12.png` | WDFo + dark + TorchRef refined |
| 13 | `panels/figure4_panel_13.png` | TorchRef + extrapolated, no map |

**Pocket panels** (`figure4_pocket.pml`):

| Panel | File | Content |
|-------|------|---------|
| 21 | `panels/figure4_panel_21.png` | WDFo + dark + extrapolated (7YYZ) |
| 22 | `panels/figure4_panel_22.png` | WDFo + dark + TorchRef refined |
| 23 | `panels/figure4_panel_23.png` | TorchRef + extrapolated, no map |

To re-render panels (requires PyMOL and CCP4 maps from validation).
All scripts use paths relative to the `paper/` directory:

```bash
cd paper
pymol figure4_difference_refinement/pymol_scripts/figure4_ligand.pml   # panels 11-13
pymol figure4_difference_refinement/pymol_scripts/figure4_pocket.pml   # panels 21-23
```
